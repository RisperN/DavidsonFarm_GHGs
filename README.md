# DavidsonFarm_GHGs
This repository contains open-source code used to generate fluxes of carbon dioxide and nitrous oxide. We characterize variability of daily soil fluxes across two plots; the first is cover-cropped fallow while the other is cropped.

REPOSITORY CONTENTS\
Two R Markdown files containing script prepared by Risper Nyairo to load relevant libraries, import data, filter flags, select a threshold for valid observations, calculate fluxes per plot-chamber-date, average fluxes across chambers, and plot the results.
